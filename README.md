# 직원태양광 등기부등본 확인 자동화

직원태양광 법인들에 분기마다 보내는 **등기부등본 변경사항 확인 메일**을 자동으로 보내고, 회신을 챙기는 Google Apps Script입니다.

담당자가 법인마다 메일을 쓰고 회신 여부를 엑셀로 확인하던 일을 대신합니다. 법인별 등기부등본 PDF를 첨부하고, 회신이 없으면 리마인드를 보내며, 그래도 답이 없으면 담당자에게 알립니다.

## 하는 일

| 시점 | 동작 |
|---|---|
| 분기 발송일 7일 전 | 담당자에게 발송 예정 사전 알림 |
| 분기 발송일 | 법인마다 등기부등본 PDF를 첨부하고 확인 항목 3가지(대표이사 주소 / 임원 구성 / 본점 주소)를 안내하는 메일 발송 |
| 회신이 오면 | 메일 답장이나 메일 속 [변경사항 없음] 버튼 응답을 확인해 `회신완료`로 기록 |
| 7일간 회신이 없으면 | 같은 메일 스레드에 등기부등본을 다시 첨부해 리마인드 발송 |
| 리마인드 1일 뒤에도 무응답이면 | 담당자에게 `[조치필요]` 보고 메일 |
| 매 실행 후 | 처리 결과를 담당자에게 요약 메일로 보냄 |

매일 오전 9시에 자동으로 실행되며, 새 분기가 되면 지난 분기 기록을 비우고 다음 발송을 준비합니다.

## 구성

| 구분 | 내용 |
|---|---|
| 코드 | `AppsScript/Code.js` (구글 시트에 연결된 Apps Script, V8) |
| 구글 시트 | `법인목록`(법인별 수신자·발송 상태 등), `로그`(처리 이력) |
| Gmail | 처음 메일은 GmailApp, 리마인드는 Gmail API(고급 서비스)로 원래 스레드에 이어 보냄 |
| 구글 드라이브 | 법인별 등기부등본 PDF 폴더. 파일 이름은 `등기부등본_법인명.pdf` |
| 웹앱 | [변경사항 없음] 버튼의 응답 화면, 담당자용 현황 대시보드 |

### `법인목록` 시트 칸

법인명, 수신자성함, 수신자직책, 수신자이메일, 참조이메일, 임원1성함, 임원1직책, 임원2성함, 임원2직책, 태양광대상자, 발송주기(개월), 다음발송예정일, 마지막발송일, 상태, ThreadID, 리마인드발송일, 회신일, 응답토큰, 응답유형, 응답일시, 변경내용, 무응답보고일

- 상태 값: (빈칸=대기) / 발송완료 / 리마인드발송 / 회신완료 / 발송실패
- 응답토큰, 응답유형 등은 스크립트가 채웁니다

## 설정: 스크립트 속성

이름·이메일·주소와 대시보드 비밀키는 **코드에 적지 않고** 편집기의 "프로젝트 설정 > 스크립트 속성"에 넣습니다. 값이 하나라도 비어 있으면 자동 실행이 **메일을 보내지 않고** 담당자에게 알림만 보냅니다.

| 속성 | 용도 |
|---|---|
| `STAFF_NAME`, `STAFF_TITLE`, `STAFF_EMAIL` | 담당자 이름·직책·이메일 (메일 서명, 알림 수신) |
| `MANAGER_NAME`, `MANAGER_TITLE`, `MANAGER_EMAIL` | 사수 이름·직책·이메일 (메일 하단 연락처) |
| `OFFICE_ADDRESS` | 본사 주소 (메일 하단) |
| `SENDER_NAME` | 보낸 사람 표시 이름 |
| `DASHBOARD_KEY` | 대시보드 비밀키. 대시보드 주소는 `웹앱 주소?key=값` |

그 밖의 설정(리마인드 대기 일수, 발송 주기, 등기부등본 폴더 ID 등)은 `Code.js` 맨 위 `CONFIG`에 있습니다.

## 실행 목록의 함수

| 함수 | 발송 여부 | 하는 일 |
|---|---|---|
| `발송전_점검` | 없음 | 이메일 형식, 응답토큰, 등기부등본 파일, 스크립트 속성을 점검해 결과를 본인 메일로 보냄 |
| `처음메일_초안_미리보기` | 없음 | 처음 메일을 본인 앞 임시보관함 초안으로 1통 만듦 |
| `리마인드_초안_만들기` | 없음 | 리마인드 대상마다 답장 초안을 만듦(확인 후 삭제) |
| `사전알림_미리보기` | 없음 | 분기 사전 알림 내용을 실행 로그로 확인 |
| `재알림_따라잡기` | **있음** | 매일 자동 실행을 지금 한 번 돌림 |
| `트리거_켜기` / `트리거_점검` | - | 매일 오전 9시 자동 실행 트리거 생성(중복이면 1개로 정리) / 개수 확인 |

이름이 `_`로 끝나는 함수는 내부용이라 실행 목록에 나오지 않습니다.

## 안전장치

- **중복 발송 방지**: 실행 잠금으로 한 번에 하나만 실행
- **법인별 격리**: 한 법인에서 오류가 나도 나머지는 계속 처리하고, 오류는 요약 메일과 로그에 남김
- **첨부 누락 방지**: 등기부등본 파일이 없는 법인은 발송을 보류하고 알림
- **드라이브 재시도**: 폴더는 실행당 한 번만 읽고, 실패하면 3회까지 다시 시도
- **응답 링크 보호**: [변경사항 없음] 버튼은 메일마다 다른 무작위 토큰(UUID)을 씀. 대시보드는 비밀키 없이는 열리지 않음

## 주의

- 트리거를 켜는 순간 대기 중인 리마인드가 바로 나갈 수 있습니다. 발송 상황을 확인한 뒤 켜세요
- 등기부등본은 분기마다 직접 발급해 폴더에 넣어야 합니다. 같은 이름으로 넣으면 가장 최근 파일을 씁니다(`주식회사`·띄어쓰기는 무시하고 비교)
- 웹앱(응답 화면·대시보드)은 **배포한 버전**으로 동작합니다. 코드를 고친 뒤 웹앱에 반영하려면 "배포 관리"에서 새 버전으로 재배포하세요
